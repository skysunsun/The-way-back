关于

这个站点叫「惊似」——取自那句老话：历史不会重演，但总会有惊人的相似。

我是孙博士，重庆交通大学交通运输学院博士研究生，平时在学术、技术与投资三条线上反复折腾。这里的文章不预测下一秒，而是记录那些反复出现的规律：技术里被验证过的工具与套路，投资里量价与情绪反复上演的剧本，研究里用数学试图抓住的行人行为模式。

目前主要分享三类：

  • 研究：行人过街意图预测（PIP）、频率域特征工程、SCI 论文写作；
  • 技术：Python、数据可视化与工程实践；
  • 投资：小资金期货交易、ETF 定投与量化筛选复盘。

内容长期维护，欢迎在 GitHub 上交流。
